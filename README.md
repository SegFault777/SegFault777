## 🚀 Featured Projects

### MiniWin
**Mini OS, Many Things.**

A small operating system project written in **C**.

A playground for learning how operating systems work by building one from the ground up.

### MiniDAW
**A DAW for all of us.**

A digital audio workstation project written in **C++**.

Exploring audio programming and what it takes to build music software from scratch.

### MiniWebEngine

A toy browser / browser engine project written in **C**.

A project for exploring what actually happens inside a web browser.

### Mixdown

A **Mixdown Markup Language** editor.

An experimental project for exploring custom languages, editors, and developer tooling.
